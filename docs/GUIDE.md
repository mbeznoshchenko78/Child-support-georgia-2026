# User guide

## Get an estimate

1. Choose the number of children in the same custodial situation. Set the income period, then type exact base pay for both parents or use the sliders. The typed amount remains authoritative when it exceeds the initial slider range.
2. Open **Income breakdown** to enter compensation outside base pay. Enter a representative average of variable income. Avoid counting a bonus or vested award again if it is already included in wages. **Adjusted income** covers the taxable self-employment base, documented earlier support payments and qualified-child proposals.
3. Enter Parent A’s annual-average parenting days. The other parent receives the remainder of the official worksheet’s 365. If residence and ordered parenting days differ, open **Residence and individual child schedules**. For equal time and equal gross incomes, enter the court’s designation or the designation you are explicitly modeling.
4. Enter each parent’s child-only health premiums and qualifying work-related care in **Insurance and childcare**. Use the separate discretionary section for proposed dental, vision and extraordinary expenses. Enter future uninsured therapy or orthodontia in the reimbursement budget.
5. Read **Guideline transfer** for the whole-dollar baseline and payer. **Calculation breakdown** shows the noncustodial column through presumptive line 10 in cents. **Calculation audit** shows both columns, table selection, rounding and subsequent adjustments. On a phone use **View calculation breakdown**.

## Compare outcomes

**Analysis lab** plots the modeled final transfer. Positive values are receipts for Parent A. Negative values are payments by Parent A. Income sweeps vary base compensation and hold other income and expenses fixed. Day sweeps model a common schedule across children. Exact chart values are available beneath the graph. Invalid combinations leave gaps. A selected heatmap cell previews its assumptions and updates the worksheet only when you choose **Use these inputs**.

Enable the current order and select its actual payer to see signed monthly and annual changes, including when payer direction reverses. The court-guideline baseline, a proposal that includes deviations, an optional percentage of income above the $40,000 table, and a separately specified negotiated or judicial hypothetical have distinct rows. The percentage is a user assumption. There is no statutory marginal rate above the table.

Choose **Save scenario**, change one assumption, then **Save as new**. In **Saved**, load, rename, duplicate, delete, or export. Compare the working scenario and up to four saved records in the lab. A direct signed difference from the working version is shown for each. Imports add records and preserve existing ones. Export the working inputs even when browser storage is unavailable.

## Build and compare parenting plans

Open **Court prep → Two-year parenting calendar**. Choose a starting date, the parent with all unassigned time, and one counting method. The overnight method assigns each night to the parent holding the child immediately before local midnight. For shorter regular daytime periods, use all hours over the two years, including overnight hours, divided by 24 and then by two.

| Example situation | Calendar rule |
| --- | --- |
| Every other Friday 17:00 to Sunday 17:00 | Alternating weeks, Friday anchor on an actual scheduled Friday, offset 0, return after 2 nights. |
| Thursday preceding the second and fourth Friday to Monday morning | Weekends by month, Friday, occurrences 2,4, offset −1, return after 4 nights. |
| Weekly four-hour afternoon visit | Every week, desired weekday, return after 0 nights, pickup and return hours on the same day. |
| Alternate summer weeks | Seasonal rotation, explicit dates and seven-day blocks. The anchor establishes which parent starts each block. Add the following year separately. |
| Holiday, school break, canceled weekend or one-time exchange | Add a dated range with the receiving parent and exact times, after the rules it overrides. Through-date 24:00 includes the entire last day. |

Later rules override earlier rules only during the overlap. **Earlier** changes precedence. The monthly calendar identifies the overnight parent in text and color. Hour totals handle Georgia daylight-saving transitions. Repeating-clock exchanges use the first occurrence with a warning. A nonexistent local time requires correction.

Copy the existing plan into the proposed plan, edit the copy, then open **Compare parenting plans**. **Apply** copies the verified noncustodial annual average into the working calculation. Later calendar edits require applying again. A proposed plan is presented as an assumed future order. For a period containing leap day, raw annual totals can add to 365.5. The official worksheet limits the noncustodial parent to 182.5 and derives the other parent from 365. The app reports incompatible counts for review.

## Prepare a hearing discussion report

Complete the evidence checklist, enter anonymized exhibit references and record the written basis for each proposed deviation. Enter the historical model’s assumed monthly amount, dates, receipts and legal basis only if applicable. Dated payments outside the interval are identified and excluded. Aggregate additional receipts should exclude dated items already entered. The dates are inclusive and each partial month is prorated by its actual number of days.

Choose **Print / PDF** and use your browser’s PDF destination. On iPhone, open the print preview and use the share sheet to save to Files. The report records both parents’ finances, line-by-line calculations, payment direction, calendar rules, proposed findings, ledger, checklist and sources. Browser printing may add a URL or date in margins if browser headers and footers are enabled.

The [five-page sample PDF](example-report.pdf) shows the opening worked example with manual parenting days. Reports distinguish a calendar you have entered from an empty calendar. Longer notes, multiple calendar rules or a detailed payment ledger can add pages.

The official Basic Information Worksheet, Schedule A Gross Income, Schedule B Adjusted Income, Schedule C Parenting Time Adjustment, Schedule D Additional Expenses, and Schedule E Deviations remain the Commission’s forms. The printable report supports discussions and exhibit preparation. [Official calculator and user guide](https://csconlinecalc.georgiacourts.gov/media/userguide2.pdf)

## Local data

Until Save or Import, the worksheet lives in memory and closing the page discards edits. The theme preference can persist separately. Local browser storage is unencrypted and separate for each browser, profile and origin. Private browsing and local-file storage restrictions vary. **Privacy and local data → Clear this app’s local data** resets only this calculator in the active browser. Delete downloaded JSON and PDFs separately if needed.
